# 올림픽공원 공연 소음 확산 트윈
(한국체육산업개발(주) 공공데이터 활용 경진대회)

올림픽공원 공연 일정, 관람객 수, 날씨 데이터로 공연날 주변 주거지 소음을 계산하고, 서울시 S-DoT 센서 실측값으로 검증해 3D 지도 위에 보여주는 웹 서비스입니다.


## 주요 기능

- **과거 공연 리플레이**: 2025년 올림픽공원 야외 페스티벌 5개를 골라 9시부터 23시까지 한 시간씩 재생하며, 소리가 바람과 건물에 따라 어떻게 퍼지는지 봅니다.
- **재개장 대비 예측**: 88잔디마당 보수 공사(2026.7~2027.6) 이후를 가정해 무대, 음향 출력, 스피커 방향, 풍향, 관객 수를 바꿔보고 주거단지별 생활소음 기준 초과 여부와 대응 방안을 확인합니다.
- **실측 검증**: 공원 주변 S-DoT 센서 8개의 실제 소음을 모델 예측, 같은 요일 공연 없는 주말과 비교합니다.



## 사용 데이터

| 데이터 | 출처 | 상태 |
|---|---|---|
| 공연명, 시간, 시간별 관람객 수 (2025) | 문화공공데이터광장 | 실제 |
| S-DoT 센서 위치, 시간대별 소음, 기온 (2025) | 서울 열린데이터광장 | 실제 |
| 건물, 도로, 호수, 공원 | OpenStreetMap | 실제 |
| 풍향, 풍속 | 계절 평균 | 가정 (S-DoT에 풍향 기록 없음) |
| 시간당 입차 대수 | 한국체육산업개발 연계 데이터 연결 예정 | 샘플 |
| 무대, 주거단지 위치, 무대 출력 | 개략 | 가정 |

```
olympic-noise-twin/
├── index.html          화면, 소음 모델, 3D 지도 (CesiumJS)
├── config.js           Cesium ion 토큰
├── osm.json            OpenStreetMap 건물·도로·호수·공원 (공원 중심 기준 m 좌표)

├── tools/
│   └── build_sdot.py   S-DoT 원본 CSV → sdot.js 변환

```

## 소음 모델

세 가지 소음을 에너지 합산합니다.

- **공연 사운드**: 무대 음원에서 거리 감쇠(20log r), 공기 흡음, 지면 효과를 빼고 풍향 보정(풍하측 최대 +5dB, 풍상측 최대 −12dB), 스피커 지향성, 야간 기온역전, 앞 건물 차폐(Maekawa 회절)를 반영합니다. 실내 공연장은 벽체 감쇠를 적용합니다.
- **인파**: 입장과 퇴장 시간대에 출입구 주변 인파 소음을 관람객 수에 비례해 더합니다.
- **교통**: 시간당 입차 대수와 주요 도로까지의 거리로 도로 소음을 계산합니다.

판정 기준은 소음·진동관리법 생활소음 규제기준(주간 65dB, 야간 60dB)을 사용합니다.


## 한계와 다음 단계

- 풍향은 가정값입니다. 기상청 시간별 관측자료나 한국체육산업개발 연계 데이터를 연결할 예정입니다.
- 시간당 입차는 샘플입니다. 한국체육산업개발 차량입출차·공연·날씨 연계 데이터로 교체할 예정입니다.
- S-DoT 센서는 대부분 도로변이라 교통 소음이 공연 소리를 덮는 경우가 많습니다. 조용한 주거지 센서에서는 헤드라이너 시간대 상승이 확인됩니다(예: 2025.10.18 20~22시, 다른 주말 대비 약 +16dB).
